Política de privacitat

Aquest web no té formularis, no fa servir galetes ni eines de publicitat, i tipografies, imatges i codi se serveixen des del mateix domini.

Estadístiques de visites

Per saber quantes persones visiten el web i quines pàgines llegeixen, fem servir GoatCounter, un servei d’estadístiques que no fa servir galetes ni identifica ningú. Per cada pàgina vista s’envia l’adreça de la pàgina, el web de procedència, la mida de pantalla i el navegador. GoatCounter dedueix el país a partir de l’adreça IP, però no la desa. No es creen perfils ni es creuen dades amb altres serveis. La base jurídica és el nostre interès legítim a conèixer l’ús del web (article 6.1.f del RGPD). Si el vostre navegador indica que no voleu ser rastrejat (Do Not Track), la visita no es compta.

Allotjament

El web està allotjat a GitHub Pages (GitHub, Inc.). Com qualsevol servidor web, GitHub pot registrar l’adreça IP dels visitants per motius de seguretat. Se’n pot consultar el tractament a la declaració de privacitat de GitHub.

Correu electrònic

Si ens escriviu a info@urnalia.es, tractarem les dades del vostre missatge per respondre-us i, si escau, preparar un pressupost o una demostració. El responsable és el titular indicat a l’avís legal. La base jurídica és la vostra sol·licitud i, si s’arriba a contractar, la relació contractual. No cedim aquestes dades a tercers, llevat d’obligació legal. Les conservem mentre duri la relació i, després, durant els terminis de prescripció legal.

Podeu exercir els drets d’accés, rectificació, supressió, oposició, limitació i portabilitat escrivint a info@urnalia.es, i presentar una reclamació davant l’Agència Espanyola de Protecció de Dades.

El programa

Urnalia s’instal·la als equips o servidors de cada entitat. Les dades que s’introdueixen al programa (membres de mesa, representants, personal) queden en aquesta instal·lació i el responsable n’és l’entitat que el fa servir. El titular d’Urnalia no hi té accés llevat que l’entitat les hi faciliti expressament per a un suport concret, i en aquest cas se signarà l’encàrrec de tractament que correspongui.
